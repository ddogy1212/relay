# 릴레이소설 📖💜

두 사람이 한 장면씩 번갈아 쓰는 무료 웹사이트. 이제 **상대가 글을 저장하면 내 휴대폰에서 자동으로 새 글을 불러옵니다.**

사이트: https://ddogy1212.github.io/relay/

## 사용 방법

1. 한 사람이 소설 제목과 두 명의 이름을 입력합니다.
2. 온라인 동기화가 준비되면 **상대 휴대폰 연결 링크**를 한 번만 공유합니다.
3. 두 번째 사람이 받은 초대 링크를 열어 연결합니다.
4. 자기 차례에 글을 쓰고 **내 장면 저장하기**를 누릅니다.
5. 상대 휴대폰은 약 12초마다 서버에 새 글을 확인하고, 화면으로 돌아올 때도 새 글을 확인합니다.

**이전에 만들었던 작품**은 집필실의 **☁ 두 사람 자동 동기화 켜기**를 눌러 기존 장면을 공동 저장소로 옮긴 뒤, 상대에게 연결 링크를 보내세요. 기존 원고 전달 링크도 호환되지만, 그 링크만으로는 자동 동기화되지 않습니다.

## 데이터 및 접근 제한

- GitHub Pages는 정적 프런트엔드, Supabase Postgres가 공동 저장소를 담당합니다.
- Supabase의 **기존 무료 프로젝트** 안에 relay_sync_로 시작하는 독립 테이블과 RPC 함수를 추가했습니다. 기존 다른 앱의 테이블 및 데이터는 변경하지 않았습니다.
- 작품마다 브라우저에서 생성한 두 개의 긴 비밀 토큰을 사용합니다. 서버에는 **SHA-256 해시**만 보관하며, 원고 열람·작성 시 토큰으로 권한을 검사합니다.
- **초대 링크 자체가 접근 권한**이므로 상대에게만 보내세요. 링크가 노출되면 제삼자가 그 작가 권한으로 원고에 접근할 수 있습니다.
- 일반 공개 API 키만 클라이언트에 포함되어 있고, 데이터베이스 관리자용 비밀 키는 포함하지 않았습니다.
- 원고 테이블에는 RLS가 활성화되어 있으며 익명 사용자가 테이블을 직접 읽거나 쓸 수 없도록 권한을 제거했습니다. 비밀 토큰을 검사하는 RPC로만 접근합니다.
- 서버가 글쓰기 순서와 최신 회차를 원자적으로 검사해 오래된 상태로 글을 덧붙이는 충돌을 방지합니다.

## 알아둘 점

- 인터넷이 필요합니다. 연결이 끊기면 글은 이 기기에 임시 저장되며, 서버에 성공적으로 저장되기 전에는 상대 폰에 반영되지 않습니다.
- **자동 동기화는 약 12초 간격의 새 글 확인 방식**입니다. 사이트가 닫혀 있어도 울리는 휴대폰 푸시 알림은 지원하지 않습니다.
- 한 번 연결한 뒤에는 매번 새 링크를 주고받을 필요가 없습니다.
- 브라우저 데이터를 지우면 그 기기에 저장된 비밀 토큰이 사라질 수 있습니다. 백업을 보관하세요.
- 무료 Supabase 저장/네트워크 한도가 적용되고, 무료 프로젝트의 일시 중단이나 한도 초과 시 동기화가 잠시 중단될 수 있습니다. **유료 업그레이드는 자동으로 하지 않습니다.**

## 테스트

- node --check app.js
- node tests/smoke.cjs
- node tests/cloud-smoke.cjs

GitHub Actions가 위 테스트에 성공한 버전을 GitHub Pages에 배포합니다. 서버의 접근 제어·차례 확인·완결 함수는 롤백 트랜잭션으로 확인하여 테스트 작품이 남지 않았습니다.

## 파일

- index.html — 소설 작성 및 상대 초대
- styles.css — 휴대폰 화면
- app.js — 집필, 임시저장, 비밀 토큰으로 동기화
- tests/smoke.cjs — 기존 로컬 저장/링크 호환성
- tests/cloud-smoke.cjs — 두 기기 자동 동기화 시뮬레이션
- .github/workflows/deploy.yml — 테스트 및 배포
