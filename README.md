# relay. — 함께 이어 쓰는 이야기

이 저장소는 **릴레이 소설**에 맞춰 만든 모바일 친화적인 정적 웹앱입니다. 로그인이나 서버 없이도 작품을 만들고, 차례를 정하고, 원고를 이어 쓰고, 다음 사람에게 넘길 수 있습니다.

## 기능

- 작품별 제목·장르·세계관·참여자 순서 설정
- 참여자가 정해진 순서대로 한 회차씩 이어 쓰는 편집기
- 이전 회차 타임라인, 이어 읽기(독서 모드), 글자 수 제한·자동 임시저장
- 랜덤 사건/문장 발상 아이디어, 등장인물 이름/집필 순서 표시
- **원고가 포함된 전달 링크** 복사 (짧은 이야기에서 사용)
- JSON 백업/복구, Markdown 원고 내보내기
- 휴대폰·태블릿·PC에 맞춘 반응형 인터페이스

## 이용 방법

1. 사이트를 열고 오른쪽 상단의 **새 소설 만들기**를 누릅니다.
2. 작가 이름과 작품 정보를 입력합니다. 참여자 이름을 순서대로 적으면 지정된 순서대로 집필합니다.
3. 한 회차를 작성하고 **이번 차례 등록하기**를 누릅니다.
4. **이야기 넘기기**에서 링크를 복사해 다음 작가에게 보내세요. 링크에는 **현재까지 원고 전체**가 포함됩니다. 받는 사람은 링크를 열고, 다음 회차를 작성해 다시 새 전달 링크를 공유합니다.
5. 원고가 길어져 링크가 너무 길어지면 JSON 파일을 내려받아 다음 작가에게 전달하고, 받는 사람이 **백업 불러오기**로 열 수 있습니다.

> **중요:** 현재 버전은 *로컬 저장 + 원고 스냅샷 전달* 방식입니다. URL만 공유한다고 실시간 공동 작업 공간이 생성되는 것은 아니며, 서로 다른 기기의 수정 사항은 자동 동기화되지 않습니다. 상대방은 **매번 최신 전달 링크나 JSON 파일**을 받아야 합니다. 보내는 링크에는 원고 내용이 들어가므로 민감한 개인정보를 쓰지 마세요.

## 배포: GitHub Pages

이 저장소에는 GitHub Pages용 Actions 워크플로가 포함되어 있습니다. 저장소의 **Settings → Pages**에서 **Build and deployment → Source: GitHub Actions**를 선택하면 `main` 브랜치에 커밋할 때마다 배포됩니다.

기본 배포 주소: **https://ddogy1212.github.io/relay/**

GitHub Pages를 켠 뒤 Actions의 `Deploy relay to Pages` 실행 상태가 성공인지 확인하세요. GitHub Pages가 아직 설정되지 않은 저장소에서는 먼저 설정을 변경해야 할 수 있습니다.

## 구조

- `index.html` 화면 및 모달
- `styles.css` 반응형 디자인
- `app.js` 로컬 저장·집필 관리·링크 및 파일 내보내기/불러오기
- `icon.svg` 사이트 아이콘
- `.github/workflows/deploy.yml` 자동 배포

외부 자바스크립트 라이브러리나 API 키가 필요하지 않습니다. 브라우저의 `localStorage`, `CompressionStream` (지원 시), Clipboard API를 사용합니다.

## 한계와 향후 확장

현재는 별도의 사용자 인증이나 서버가 없으므로, **진짜 실시간 협업**, 작성자 신원 검증, 여러 기기 자동 동기화, 댓글/투표 등의 서버 기반 기능은 제공하지 않습니다. 이런 기능을 추가하려면 Supabase 같은 백엔드와 접근 제어(RLS)를 연결해야 합니다.
